# Response-field orientation

The raw conversation route must not begin with a caller-selected topic or read shape. An admitted observation first perturbs the typed substrate and measures the finite set of crossings that answer that perturbation.

The native response field preserves, per responding canonical entity, distinct source-state incidence, relation-family mass, provider/source-plane mass, direction, multiplicity, structural gap, and independent evidence roots. These channels are not collapsed into one relevance scalar.

`laplace_cognition_response_field_scan` performs the bounded set-wise propagation. It starts from the admitted observation root, enumerates all admissible typed provider crossings in frontier batches, assigns every crossing a scan-global source-state ordinal, advances distinct path states, and folds the resulting candidate estate with `laplace_cognition_response_field_measure`. Incomplete provider boundaries and resource exhaustion publish no candidate/response prefix.

The raw prompt conversation path executes this scan before `laplace_cognition_turn_compile`. The scan uses the full relation-family mask so prompt meaning is not preselected by the caller. The caller's relation mask is treated only as an admissibility envelope after the response is known. The active cognition relation mask is the intersection of that envelope and the families that actually responded. A supplied goal must itself be present in the measured response field; an unrelated caller-injected goal is rejected. When that admissibility check rejects caller intent after a complete scan, the completed orientation receipt remains published as the rejection witness while conversation state, response bytes, and next discourse remain unpublished.

The response-field receipt is bound into a derived orientation context before the cognition request is compiled. Consequently two admitted observations with different typed back-reaction cannot silently compile to the same turn context merely because a caller supplied the same policy.

This is the native sparse counterpart of the role conventional systems assign to query/key interaction: the query is the current observation/discourse/obligation state, keys are the typed indexed addresses that can respond, values remain their separately typed physicality/testimony/calculation/geometry/standing state, and the fold updates the active context. No transformer tensor or learned embedding is required for the native mechanism.

This implementation is deliberately not the final interpretation compiler. The response field is the missing orientation substrate that must feed witnessed joint interpretation and program/goal derivation. Until that later compiler can derive a task program, a supplied goal is constrained to the observed response field rather than accepted as semantic authority.
