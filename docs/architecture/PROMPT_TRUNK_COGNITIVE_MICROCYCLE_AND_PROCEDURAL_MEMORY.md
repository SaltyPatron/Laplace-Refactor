# Prompt-trunk cognition, finite active operations, habits, and muscle memory

Status: inventor-direct architecture clarification, 2026-09-02. This record is additive to the Constitution, Invention Model, `COGNITION_EXECUTION.md`, #17, #18, #19, #129, #132, #168, #169 and #170. It preserves all prior work and narrows several terms that were still too easy to misread as a conventional tokenizer/topic/transformer pipeline.

## 1. The admitted user prompt becomes one exact cognition root

A user interaction such as:

```text
How does lightning work?
```

is first admitted as ordinary Laplace content. Its exact bytes/content are decomposed through the selected Unicode/UAX/grammar recipes and deposited into the same canonical Merkle-DAG/physicality machinery as any other text.

The result includes a canonical trunk/root composition identity for the complete prompt.

```text
prompt trunk entity id
    = exact canonical content root for the whole request

prompt occurrence / witness
    = this user/session/turn/source observed that exact content here
```

User, session, turn, time, source and authority do not salt the canonical prompt identity. They are witnessed occurrence/context state around that identity.

The trunk is the initial addressable operand for cognition. The processor does not need to begin from a bag of words or elect one constituent. It can descend from the trunk to constituents, rise through usages/containers, inspect the enclosing conversation, join facts/relations/calculations, and retain every transition in the request receipt.

## 2. Any addressable Laplace state can become a later cognition source

Once content, a calculation, an execution receipt, a failed program, a semantic act, a document, a source profile, a chess game, generated code, or another state is admitted and addressable, a later cognition program can use that identity as an input/root operand.

This permits recursive/self-referential work without inventing a private scratch-language:

```text
user prompt trunk
    -> cognition execution
    -> result / receipt / failure / program candidate
    -> admitted addressable state
    -> later cognition may inspect that state as an operand
```

Examples include:

- reason about why a previous answer was incomplete;
- inspect its own provider/search receipt and propose a cheaper plan;
- compare two prior cognition programs;
- inspect generated code or a model export as ordinary content;
- ask which evidence caused a referent/sense decision;
- use a failed execution as input to Gödel discovery;
- generate a question/experiment whose answer would discriminate unresolved hypotheses.

Self-use does **not** create independent evidence. A Laplace-generated descendant retains derivation ancestry and cannot independently corroborate the state/program that generated it. Recursive cognition is addressability and computation, not self-certification.

## 3. UAX29 starts observation; it does not decide interpretation

For text, the prompt trunk can expose structural altitudes such as:

```text
Unicode positions / codepoints
-> grapheme boundaries
-> word/segment candidates
-> phrase/clause/sentence/utterance compositions where supported
-> punctuation / whitespace / gaps
-> ordinal / containment / recurrence / trajectory
-> enclosing session / discourse structure
```

UAX29 supplies standards-defined segmentation boundaries. It does not decide topic, importance, semantic act, referent, emphasis, omitted arguments, syntax, or meaning.

The cognition machinery must remain language-agnostic at the execution-contract level. Language/grammar-specific behavior is selected through evidence/providers/recipes rather than hardcoded English order assumptions.

The same logical processor must therefore handle materially different structures, for example:

```text
English-like surface:
    How does lightning work?

Japanese-like surface:
    particles, topic marking, omitted arguments, different constituent order,
    script/segmentation behavior, and discourse-dependent emphasis
```

The two surfaces may eventually justify the same semantic program, but they need not reach it through the same exact structural route. Equivalence is a conclusion supported by language/semantic evidence, not a normalization that erases the original structure.

Seed sources such as UCD/UAX, UD Treebanks, OMW/WordNet, FrameNet/PropBank/VerbNet/SemLink, dictionaries, observed documents/dialogue and later learned usage provide different typed evidence for this orientation. No one source owns the language interpreter.

## 4. The fixed part is the cognitive microcycle, not a fixed answer path

Laplace needs a stable processor loop whose stages have fixed meanings while the operations selected inside the loop remain query-relative.

A representative logical microcycle is:

```text
OBSERVE exact trunk + current persistent state
-> ENUMERATE eligible typed operations/providers
-> PREDICT each operation's effect on unresolved obligations
-> SCHEDULE a bounded operation/batch under firmware + resource policy
-> EXECUTE against indexed structural/semantic/calculation/evidence state
-> FOLD the typed result into guidance state
-> CHECK what became resolved, contradicted, ambiguous or newly required
-> WITNESS the execution/result
-> repeat while the semantic act remains incomplete and resources permit
```

This is the sense in which the processor can be fixed while cognition remains open-ended. The fixed loop does not say `lightning is the topic`, `English WH-word means explanation`, or `take two graph hops`. It says how the machine chooses, executes, evaluates and remembers operations.

## 5. Finite active operation vocabulary; combinatorially large instantiated machine

Conventional neural architectures use a finite catalog of operation families in a given architecture/version: projections/matrix products, dot products, normalization, nonlinearities, attention/softmax/gating, routing, reductions, sampling/selection and related calculations. The number of learned parameters, layers, heads and runtime states can be enormous even though the active primitive operation vocabulary is finite.

Laplace should use the same distinction without copying transformer ontology.

At any **active calculus/ISA epoch**, the legal primitive/derived operation catalog is finite and versioned. Gödel may propose a later extension, so the catalog is extensible across epochs, but a running program never relies on an undefined infinite instruction set.

The open-ended scale comes from composition and instantiation. A useful mental model is:

```text
finite operation families
  x structural altitude/tier
  x relation family/direction/role
  x source/evidence/dependence scope
  x language/grammar/sense candidates
  x world/time/discourse/context
  x geometry/trajectory/window
  x standing lane/uncertainty
  x goal/completion obligation
  x resource/authority state
  = enormous query-relative operator/program space
```

A `head`, `layer`, `tensor`, `expert`, or similar conventional-model role can therefore shake out as a compiled consumer view of one selected subset of these typed jobs. It is not required to pre-exist as one permanent native matrix.

## 6. Native layers and heads are dynamic jobs, not permanent slots

For native cognition:

- a **layer-like step** is one or more cognition microcycles that transform guidance state by resolving obligations or changing representation;
- a **head-like job** is a concurrently or independently useful typed operator/provider lane selected for the current state;
- a **tensor/operator** is a query-relative materialization or virtual calculation over selected substrate state;
- an **expert-like program** is a reusable typed program applicable under declared preconditions/context.

A prompt may therefore instantiate different effective heads/jobs for syntax, occurrence usage, causal relations, definitions, discourse references, geometry, standing, deterministic calculation, contradiction or another requirement. Another language or goal can instantiate a different set without changing the processor ISA.

For target-model export, #129 may compile those selected jobs into conventional Q/K/V/O/FFN/head/layer roles. Q/K/V/O remain consumer roles, not the definition of native cognition.

## 7. Habit formation is learned operation scheduling

A habit begins only after primitive cognition has generated enough persistent successful **and failed** execution trajectories for Gödel to propose a reusable program.

The progression is:

```text
primitive executions
-> persistent typed receipts/outcomes
-> recurring structural + semantic state motif
-> candidate reusable program/skill
-> held-out evaluation + counterexample search
-> explicit activation
-> repeated successful use under valid preconditions
-> firmware scheduling preference = habit
```

The trigger for a habit is not a surface string. It is a versioned state signature that may include:

- current semantic-act/goal candidates;
- unresolved obligation shape;
- structural/grammar motif;
- bound and unresolved referents/senses;
- discourse/world/time state;
- eligible provider/evidence state;
- prior outcomes/counterexamples;
- resource cost and expected obligation reduction.

That allows a learned mechanism-explanation skill to be proposed for structurally different languages/paraphrases when their justified semantic state matches, while rejecting superficially similar utterances whose semantics do not.

A habit changes **which proven program is considered/scheduled earlier and with how much exploratory work**. It never changes truth, canonical identity, or current preconditions.

## 8. Muscle memory lives below semantic program selection

Muscle memory is not another stronger habit score.

Once a skill/program has stable semantics and repeated measured use, Gödel may notice that its primitive execution repeatedly spends work in the same physical shape. It can propose an acceleration candidate.

The semantic and physical decisions remain separate:

```text
Gödel / procedural-memory layer
    determines that a reusable skill is semantically valid
    and that repeated traces justify testing an acceleration

firmware
    determines when that skill is worth proposing/scheduling for current state

physical-plan / compiler / perfcache / native provider layer
    determines how the already-selected logical skill can execute more cheaply
    on this product/hardware/provider generation

activation authority
    publishes the accepted accelerated generation
```

Possible muscle-memory embodiments include:

- fused typed ISA operation;
- vector/batch kernel fusion;
- prepared set-wise PostgreSQL/native provider plan;
- dedicated index or immutable perfcache plane;
- materialized operator plane;
- native compiled fast path;
- memoized closed-epoch result/operator region;
- more efficient but semantically equivalent frontier/search physical plan.

The acceleration must preserve the primitive program's logical result, evidence boundary, completion law and receipt meaning. If it changes semantics, it is a new candidate skill/program, not muscle memory.

## 9. Practice changes path cost before it changes truth

The intended learning analogy is therefore mechanical rather than rhetorical.

Repeated experience can cause:

```text
first encounter:
    broad interpretation search
    many discriminating provider reads
    primitive program construction
    expensive execution

repeated validated encounters:
    reusable skill exists
    habit proposes it earlier
    fewer exploratory branches are required
    prepared/indexed/fused physical path may exist

well-practiced stable case:
    current preconditions still checked
    skill fires through cheap muscle-memory path
    result remains fully receipted and replayable
```

This resembles the useful computational aspect of automaticity: practice can reduce deliberative search and physical work without converting the learned procedure into unquestionable truth.

## 10. `How does lightning work?` under this model

The first time through, nothing is privileged except the exact prompt trunk as the source/root observation.

```text
prompt trunk
-> descend/inspect complete structure
-> inspect occurrences/usages of candidate constituents and constructions
-> retain language/grammar/sense/referent/act hypotheses
-> schedule discriminating structural + semantic + discourse operations
-> fold evidence
-> eventually bind a mechanism-explanation semantic program if justified
-> execute causal/process obligations
-> realize answer
-> witness result + complete execution trajectory
```

After many independent examples, Gödel may induce a reusable mechanism-explanation skill. English `How does X work?`, a Japanese construction, a paraphrase such as `What is the mechanism behind X?`, and a domain-specific request can all reach that skill through different structural paths if their semantic state justifies it.

The skill does not mean `X` is always the topic. The habit does not mean `how does` is a regex. Muscle memory does not mean skipping interpretation. Each optimization removes rediscovery only where the current state proves the preconditions that were previously learned.

## 11. Brain analogy: useful boundary, not a biological identity claim

The engineering analogy is strongest at the systems level:

```text
persistent experience
-> repeated activation trajectories
-> learned action/program selection
-> proceduralization / automaticity
-> cheaper execution of practiced behavior
```

Neuroscience does not reduce human habit or skill learning to one brain structure or one universal mechanism. Basal-ganglia/striatal circuits are strongly implicated in action selection, skills and habits; cerebellar and cortical circuits also contribute to motor learning/consolidation and interact with those systems. Laplace should therefore avoid claiming that one table or subsystem is `the basal ganglia` or `the cerebellum`.

The useful design lesson is distributed responsibility: semantic program discovery, scheduling policy, execution optimization, memory, outcome feedback and replay are distinct cooperating systems.

## 12. Acceptance consequences

A conforming product must prove:

- a user prompt is deposited as an exact canonical trunk plus independently scoped occurrence/witness context;
- the cognition receipt starts from that trunk and never requires a preselected constituent/topic;
- any addressable prior Laplace result/receipt/program may become a later cognition operand while self-ancestry remains explicit;
- generated descendants cannot independently corroborate their own ancestor program/evidence;
- the execution microcycle is language-agnostic while language-specific structural/semantic providers remain selectable and replaceable;
- equivalent semantic acts can be reached from materially different language structures without flattening those structures first;
- the active operation catalog is finite/versioned, while selected operator/program instantiations are query-relative and compositional;
- dynamic native jobs can compile into target heads/layers/tensors without making those target roles native ontology;
- habit promotion changes scheduling only after held-out/counterexample validation;
- muscle-memory promotion occurs only after stable skill semantics and measured repeated physical work;
- an accelerated route proves semantic/receipt parity against the primitive route;
- changing context/language/goal/evidence can invalidate a habit or force fallback to primitive cognition;
- the whole chain remains inspectable through the context-preserving workbench/receipts rather than hiding learned dispatch.

## 13. Deliberate defects

Reject:

- ephemeral prompt strings with no canonical trunk/occurrence record;
- treating the prompt trunk as a topic ID;
- one English word-order/WH regex as the cognition compiler;
- spaces required for universal word segmentation;
- Japanese/other languages normalized into English order before cognition;
- fixed noun/content-word weighting used instead of whole-observation interpretation;
- an unbounded or undefined runtime operation vocabulary;
- one permanent universal head/layer/tensor schedule presented as native cognition;
- self-generated reasoning counted as independent evidence;
- habit as mandatory hidden dispatch;
- muscle memory chosen only from frequency without stable semantics/counterexamples;
- semantic changes hidden inside a `fast path`;
- a target Q/K/V/O mapping imported back as native ontology;
- performance improvement that cannot be replayed to the primitive program and exact receipt boundary.
