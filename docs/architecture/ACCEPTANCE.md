# Product acceptance

## Standard of proof

Acceptance tests execute the product implementation through public contracts and
assert exact outcomes, persistent state, and receipts. Source-text inspection can
enforce repository structure but cannot prove product behavior.

Every critical acceptance has a deliberate defect variant. The test is trusted only
after the defect makes it fail for the expected reason.

Every suite also proves that it selected and executed at least one real target, records
the source, built, staged, packaged, installed, and loaded artifact identities, and
retains the implementation trace that produced the asserted result.

Every generated cross-layer representation proves that it preserves the distinctions
required by its declared consumers or that its receipt reconstructs them exactly.
Mutation fixtures erase relation type, direction, arity, evidence lineage, rank, or
context one at a time and must fail before the generated representation is accepted.
A target-shaped value and a loadable artifact are not behavioral proof.

## Identity

- Identical canonical content entering through different sources, languages, models,
  machines, batch sizes, and product APIs produces the same identity.
- Every identity is exactly 16 bytes from the fixed SIMD-optimized BLAKE3 content
  contract and matches generated native, SQL, and C# vectors.
- Numeric `255` has one content identity across channel, address, byte, sample, model,
  game, and instruction roles; role changes testimony and surrounding structure, never
  the content ID.
- Tier, type, source, modality, coordinate, ordinal, time, and trust mutations cannot
  change content identity.
- Empty content, absent value, zero identifier, and sentinel states remain distinct.
- Different content never merges because of a label, coordinate, source, or storage
  position.
- Equal normalized names never establish equal referents. Name content, name
  occurrences, candidate people, source-scoped identifiers, identity testimony, and
  referential adjudication epochs remain distinct and independently queryable.
- A temporal contradiction against a candidate person merge retains both observations
  and produces a derived split hypothesis; it cannot delete source content, assert the
  split as observed, or rewrite the prior referential epoch.
- Canonicalization versions and transformations remain visible and reversible where
  their contract requires it.
- Precomposed and decomposed Unicode sequences retain different exact content IDs while
  a versioned Unicode-equivalence relation makes their declared semantic relationship
  queryable.
- One entity can have multiple immutable calculated physicalities and contradictory
  type attestations without any change to its content ID.

## Universal modality

- Equivalent engine programs operate over text, image, audio, video, code, game, and
  model-derived values with the same instruction semantics.
- Cross-modal queries accept one modality and materialize another with a complete
  receipt.
- Engine behavior does not contain a text-only semantic branch.
- Decode, engine, database, and encode time are reported separately and together.

## Unicode and physicality

- With no Tier-0 rows and no active atom plane, one Unicode decomposer execution reads
  a pinned standards manifest, calculates each canonical atom record once, writes the
  bootstrap artifact, and supplies those exact records to the database bulk sink.
- The seeded database and cache match in standards fingerprint, calculation-recipe
  fingerprint, cardinality, ordered-stream digest, partition digests, identity bytes,
  coordinate bit patterns, Hilbert keys, DUCET records, and declared UCD properties.
- A deliberately changed database serializer, cache serializer, source file, record
  order, or numeric bit pattern prevents activation even if row counts match.
- A stale or independently calculated cache cannot seed the canonical rows merely
  because its version label matches. A newly produced receipt-bound bootstrap artifact
  from the same decomposer execution may precede database deposition.
- Failure before the activation commit leaves the prior coherent epoch active. No
  reader or dependent ingestion can observe a new database/cache half-pair.
- The atom plane covers exactly 1,114,112 codepoint positions, including assigned,
  unassigned, reserved, surrogate, and noncharacter positions.
- Complete DUCET order is independently verified for explicit and implicit weights,
  expansions, contractions, canonical equivalence, algorithmic Hangul, and the total
  rank permutation.
- Atom coordinates match the declared super-Fibonacci recipe within the exact numeric
  contract.
- The fixed Unicode population count is an input to the bounded Super-Fibonacci
  recipe. Adding deposited content above Tier 0 cannot move an atom within its
  geometry epoch.
- The Hopf map of every atom lies on the declared S2 base; polar-height and both fiber
  phase distributions pass the pinned complete-population conformance bounds.
- A 3D glome view declares its 4D rotation and projection. Two points separated only
  in the fourth component remain distinguishable under a suitable declared rotation,
  and no projected coordinate can be written back as canonical physicality.
- Composite coordinates equal an independent four-dimensional arithmetic accumulation
  over live child points, including multiplicity, and retain the resulting radius.
- Hilbert encoding uses four 32-bit axes and round-trips declared cells and boundaries
  to one byte-sortable 128-bit key.
- Packed trajectories retain exact child IDs, logical ordinals, run counts, and typed
  metadata; Fréchet operates only on realized live coordinates.
- Injected sphere projection, private modality atoms, coordinate-as-identity, and
  packed-value-as-coordinate defects all fail.
- Two distinct compositions deliberately constructed with the same centroid and radius
  remain distinct by content, constituents, multiplicity, and trajectory.
- A source MIME or filename claim cannot instantiate physicality. A calculated
  physicality and a derived classifier attestation preserve separate recipes and
  receipts.
- Repeated observed uses add occurrence/context records without changing the entity or
  any prior physicality.
- A multi-atom content entity such as `Hello` retains one identity and one proven tier
  floor when used as a word, a one-word utterance, or a complete sentence. The latter
  roles and structural altitudes belong to realized occurrences; a one-child wrapper
  cannot mint another entity or database key.
- Trunk-to-leaf trajectory reconstruction directly reproduces constituent identities,
  roles, ordinals, runs, tier paths, ancestry, containment, precedence, recurrence,
  shape, dimensions, centroid, radius, and locality without testimony or consensus.
- Changing source trust or consensus cannot change an exact physicality-derived
  structural fact; changing a trajectory byte must change or invalidate the calculated
  structure and receipt.
- A mapped Unicode atom plane resolves identity, coordinate, locality, and segmentation
  inputs without PostgreSQL. Leaf-to-trunk composition calculates the complete candidate
  Merkle DAG in memory, whole-working-set dedup merges equal identities, and durable
  presence uses no more than one set-oriented round per participating tier.
- Dense planes prove direct-address behavior. Sparse and variable-result planes prove
  their declared ordered or module-specific complexity. Replacing either with one
  universal sequential scan or generic binary-search layout fails the access-law contract.
- A corpus-derived perfcache cannot publish during canonical loading. It builds from a
  closed durable ETL boundary, passes semantic parity and integrity verification, and
  activates atomically while readers retain the preceding coherent epoch.

## Language and model independence

- Conversation and query scenarios execute across different scripts and languages
  without Latin punctuation or English word-order rules in the engine.
- Shared content and concepts connect across language evidence while preserving exact
  surface identity.
- Two model families can be ingested, compared, and used as competing witnesses.
- An output artifact can target an architecture unrelated to either source model.
- A tier-3 Japanese sentence decomposes into the exact ordered tier-1 constituent
  trajectory and renders the original sentence without an English token assumption.
- The clean implementation independently reproduces the preserved direct compilation
  baseline: substrate attestations become model tensors, a GGUF target loads in an
  external runtime, and deterministic prompts expose both relation signal and defects.

## Evidence and adjudication

- Confirmation, refutation, uncertainty, unknown, and missing testimony remain
  distinct through ingest, persistence, adjudication, query, and receipt.
- Competing propositions remain addressable with every occurrence, proponent, source,
  context, contradiction, and historical standing even when one currently has much
  lower standing. Adjudication never deletes the lower-standing proposition.
- Source trust, source-type trust, relation trust, model trust, and context can vary
  independently and change results according to the declared mathematics.
- Repeated positive evidence cannot turn adjudication into a disguised hit counter.
- A round-earth/flat-earth fixture proves that cross-domain independent observations,
  calculated geometry, successful predictions, causal compatibility, and source
  dependence affect standing differently from copied assertion volume. One thousand
  dependent repetitions cannot outweigh independent convergence merely by count.
- Testimony remains inspectable after standing state changes.
- Recorded and calculated testimony can be independently included, excluded, and
  compared.
- Witnessed, copied, derived, independently corroborated, and currently believed state
  retain different encoded epistemic kinds through persistence, query, and receipts.
- Every derived claim reaches its complete root-observation set through an acyclic
  provenance DAG. A derivation cycle is rejected and a thousand descendants of one
  root cannot increase independent support beyond that root.
- Mirrors, quotations, syndication, shared primary sources, duplicated datasets,
  model ancestry, fine-tunes, and distillation produce dependence edges that change
  effective independent evidence under the declared adjudication mathematics.
- Consensus epochs are immutable and reproducible from exact testimony boundaries.
  As-of queries return prior standing after newer evidence changes current standing.
- Laplace query or inference output alone cannot certify these properties; each test
  includes an independent calculation or externally observed result.
- Person resolution discounts copied game databases and shared source ancestry,
  preserves unresolved candidate sets, and treats external identifiers as
  source-scoped testimony rather than content identity.

## Conversation

- A multi-turn discussion of a connected subject carries entities, relations,
  unresolved references, corrections, and prior results through persistent substrate
  state.
- Requests sharing one topic but asking for definition, cause, comparison, correction,
  calculation, clarification, and counterfactual consequence compile distinct typed
  goals and completion predicates. One fixed descriptive read cannot satisfy them.
- Prompt compilation is accepted only when the declared operation inventory has
  behavioral fixtures; success on one definitional operation cannot certify the
  general compiler.
- A relational request retains every participating entity, role, direction, negation,
  temporal boundary, decisive function word, and discourse binding. Electing one topic
  cannot erase the rest of the request before planning.
- Working discourse state includes active propositions, unresolved questions,
  corrections, ellipsis, references, and cross-modal artifacts. Recent topic identity
  and recency ranking alone cannot satisfy this state contract.
- The water-cycle scenario connects rain, clouds, water, evaporation, condensation,
  and precipitation instead of returning isolated dictionary entries.
- The same scenario executes in multiple languages and with at least one image or audio
  turn.
- A correction changes subsequent selection while preserving the earlier testimony.
- Fact selection, connective scaffolding, and nonempty output cannot establish semantic
  act completion or language realization. Reused and newly generated compositions have
  different receipts.
- Fast cognition, evidence-epoch learning, and calculus-extension discovery remain
  separately replayable even when each changes later conversational behavior.
- A request requiring search proves logical-program lowering into the common typed
  search ISA. A separately callable entity-path query is insufficient if the
  conversation path does not invoke the lowered program.
- An unsupported question returns an explicit unknown result with a receipt.
- SQL, HTTP, CLI, and other transports produce equivalent program semantics.

## Ingestion exactness

- Every input record has an exact disposition and receipt.
- Exact accepted, rejected, duplicate, transformed, testified, and persisted counts
  reconcile from source to database.
- Repeating an identical ingest satisfies its idempotency contract.
- Cancellation and process termination expose the exact durable boundary; no partial
  source is reported complete.
- Parallel and serial runs produce identical identities, testimony, standing state,
  and receipts.
- Batch-size changes do not change meaning.
- Run, file, segment, batch, record, database, and receipt counters form a disjoint
  hierarchy whose children reconcile exactly to each parent.
- Source completion requires every declared file identity and record disposition; a
  later successful sub-run cannot replace an incomplete source state.
- AI-agent archives from every discovered provider retain messages, tool calls,
  results, artifacts, every known field, unknown fields, exact session relationships,
  and physical trajectories through the generic ingest spine.

## Canonical deposit and derived state

- Content, structure, physicality, occurrence, testimony, and their receipts deposit in
  bounded append-oriented batches without a serialized update to one mutable consensus
  row per input proposition.
- Derived adjudication, reproducible statistics, materialized relations, and indexes
  name their exact testimony boundary, dependence graph, recipe, engine, and epoch.
- A derived epoch remains invisible to latest-complete queries until its counts,
  receipts, and semantic checks reconcile; publication is coherent.
- Deposit-complete, derived-state-complete, and complete-ingest are distinct receipt
  states. Only the last satisfies complete ingest acceptance.
- Rebuilding any reproducible derived state from the same canonical boundary produces
  the same semantic result and declared deterministic bytes.
- Canonical structural edges, retained testimony, reproducible statistics, retained
  inference results, active working state, and acceleration artifacts have different
  storage classes and lifecycle contracts.
- A combinatorial fixture proves that derivable co-occurrence and pairwise statistics
  grow under a declared materialization bound rather than all possible pairs being
  persisted.
- Batch count, not row count, bounds native calls, SPI plans, transactions, mutable
  contention points, and derived-state publication operations.

## Repetition and sparse deposition

- Expanded and run-span inputs produce identical BLAKE3 IDs, arithmetic centroids,
  logical ordinals, readback, containment, testimony, and receipts.
- Runs exceeding 65,535 occurrences split into consecutive encoded vertices without
  losing total count or source ordinal.
- A repeated sky-blue pixel and repeated sky-blue patch create one entity and one
  physicality per distinct content node while retaining every occurrence and parent.
- Million-digit numeric content and repeated media execute without constructing a
  million-element temporary identity array.
- Re-ingestion avoids already-proven entity and physicality writes and still records
  source occurrence and testimony exactly.

## Performance

Hardware acceptance uses the Intel i7-6850K system and its declared storage layout.

- Complete ingest: at least 500,000 input records per second.
- Complete ingest: no more than 30 seconds per GB for qualifying real corpora.
- The timing starts with the first source byte and ends after exact durable state and
  receipts are independently visible.
- Input construction, parsing, canonicalization, composition, database work,
  adjudication, indexes, and completion verification remain inside the measured
  boundary.
- Tests use real inputs of sufficient size. Small-fixture extrapolation is rejected.
- Results include median, tail, repeated samples, CPU utilization, physical cores,
  memory high-water mark, allocation counts, I/O bytes, waits, locks, database calls,
  rows, and WAL.
- Every corpus declares exactly what one input record means and reports input bytes,
  logical occurrences, distinct entities, physicalities, compositions, testimony,
  derived edges, durable writes, and cold or warm state in addition to records per
  second and seconds per GB.
- Every stage has throughput and time accounting that reconciles to total wall time.
- Bulk execution demonstrates bounded crossings and database calls rather than one call
  per record.

## Planner and server behavior

- Representative SQL programs include `EXPLAIN (ANALYZE, BUFFERS, WAL)` evidence.
- Tests prove required indexes are selected at representative cardinality and degree.
- Every published index names its workload, representative cardinality and degree,
  expected plan, scan threshold, write cost, storage cost, and removal condition. An
  unused index or an index whose plan contract fails cannot pass package acceptance.
- Native server plans are prepared, parameterized, schema-qualified, and reused under
  their declared lifetime.
- Query results remain exact when planner choices and batch sizes change.
- Installed SQL functions use explicit namespaces, parsed bodies where required, and
  no hidden session configuration as semantic input.
- The SQL operation inventory proves one generated binding per ISA instruction and no
  temporary or handwritten second semantic implementation.

## Perfcaches

- Every plane registers through one native typed module ABI and declares key, value,
  dependencies, source fingerprint, recipe fingerprint, canonical operation, resource
  shape, and integrity digest.
- Whole-artifact checks, overflow-safe section validation, semantic record validation,
  and exact file-length checks reject deliberate corruption.
- An artifact with a newly computed valid checksum but incorrect content ID,
  coordinate, ordering, or lookup value is rejected by canonical semantic comparison.
- Modules publish through verified atomic replacement and activate only inside a
  coherent artifact-set epoch.
- A replacement generation is fully mapped, validated, and prefaulted before its
  registry epoch becomes visible. Existing statements and ISA programs retain their
  pinned generation until completion; new work observes the new generation.
- Updating a deterministic perfcache generation requires no postmaster restart. A
  deliberate implementation that refreshes a data epoch only through PostgreSQL
  restart fails availability and lifecycle acceptance.
- Each module can be replaced independently when its declared dependencies remain
  compatible; every running process reports its exact loaded artifact identity.
- Batch lookup returns the same values, misses, errors, and ordering as canonical
  execution and does not create per-record process or database crossings.

## Model ingestion and target construction

- Ingest preserves model structure, values, identities, and calculated observations
  required by its declared contract.
- Ingested query, key, value, output, embedding, normalization, feed-forward, gating,
  routing, positional, and architecture-specific values remain attributable model
  testimony rather than becoming substrate authority.
- Typed relation kernels calculate pairwise targets from declared substrate evidence;
  fitting and factorization reproduce those targets within declared numeric bounds on
  both training and withheld observations.
- Head-specific operators exhibit the declared relation behavior. Shuffling the
  relevant evidence, removing one required relation family, transposing a factor, or
  omitting one selected operator must fail its mechanism and downstream behavior tests.
- Value and output operators are tested against witnessed contextual transformations,
  not merely tensor dimensions or nonzero output.
- An invertible change of basis applied to Q and the compensating inverse transform
  applied to K must preserve the induced bilinear operator and its behavior while
  changing raw factor identities. Raw tensor similarity must not classify the factors
  as different semantics.
- Head permutation, feed-forward neuron permutation, and compensating scale fixtures
  compare as equivalent only when their induced functions and outputs agree under the
  declared probe set.
- Source-model architecture does not constrain another source or target.
- Target artifacts pass format validators and execute in their declared runtime.
- Semantic behavior, not file existence or size, determines acceptance.
- Every target value traces to selected substrate state and instructions.
- Declared, selected, emitted, loaded, and executed operator sets reconcile exactly.
- Exact target closure includes embeddings, attention, normalization, feed-forward,
  gating, routing, positional conventions, metadata, layout, quantization, and every
  architecture-specific tensor selected by the target program.
- GGUF output loads in the declared runtime with exact tensor names, dimensions,
  layouts, numeric conventions, metadata, and quantization, then passes behavioral

- The native and PostgreSQL implementation constructs and evaluates the required

- Embedding retrieval, reranking, an attention block, a decoder, and the complete

- Every target executes the water-cycle conversation and the broader conversational
  acceptance corpus in its declared runtime.

## Cognition and inference

- Relation algebra accepts every declared legal composition and rejects converse,
  symmetry, and transitivity errors with counterexamples.
- A cognition request compiles into a typed logical plan and a costed vector-first
  physical plan. Equivalent physical plans return equivalent semantic state and
  receipts.
- A goal-directed request compiles its initial states, terminal predicate, enabled
  typed transitions, hard constraints, accumulated cost, remaining-cost estimate,
  evidence epoch, duplicate/reopen policy, tie rules, and completion certificate.
- Native, PostgreSQL, PostGIS, trajectory, physicality, occurrence, relation, and
  perfcache indexes generate bounded frontier batches. A per-row client expansion or
  unbounded in-memory edge load fails the scalable search contract.
- An A-star optimality claim matches an independently solved fixture and proves
  admissibility, consistency or explicit reopen behavior, canonical state identity,
  deterministic ties, and terminal completion. An overestimating heuristic cannot
  retain an optimality claim.
- A search that orders accumulated cost first and consults remaining cost only on exact
  ties reports uniform-cost semantics rather than A-star. The executed priority law
  must match the algorithm named in the receipt.
- Bounded search state retains every resource dimension needed for completeness. A
  cheaper deep arrival cannot suppress a costlier shallow arrival that alone has
  enough remaining depth to reach the terminal state.
- Requested path multiplicity, diversity, and ordering are executed and receipted; an
  ignored path-count argument fails the result contract.
- Set-oriented frontier expansion replaces one server query per frontier state and
  reports crossings, plans, rows examined, emitted states, and elapsed time.
- Target identity plus scalar cost cannot erase transition type, direction, layer,
  relation law, source, evidence roots, context, index source, or cost components.
- A metric top-k result can seed a frontier but cannot replace the complete cognition
  program. A fixture whose nearest geometric candidate violates evidence and context
  must select the supported goal state instead.
- Angular, Fréchet, Hausdorff, Karcher-derived, Hilbert, structural, occurrence,
  semantic, and epistemic neighborhoods pass crafted fixtures where their orderings
  disagree. One scalar affinity must fail at least one fixture.
- Glicko-2 query standing retains source trust, source-type trust, relation type,
  independent roots, dependence, contradiction, context, valid time, and consensus
  epoch. Its query-specific rank cannot be published as timeless substrate meaning.
- Typed relation laws generate distinct incidence and transport calculations. Replacing
  them with one scalar adjacency or pairwise-similarity graph fails direction, n-ary
  composition, relation-law, and exact-reconstruction fixtures.
- Evidence metrics account for root independence and dependence. Copying one root one
  thousand times cannot create the operator conductance of one thousand independent
  observations.
- Matrix-free operator application and any published materialized acceleration agree
  under the declared numerical contract.
- Exact field fixtures independently prove boundary conditions, null-space behavior,
  solver residual, typed compatibility energy, and source response.
- A zero solver residual does not report a frayed edge. Existing relation, boundary,
  motif, contradiction, innovation, and counterfactual defects activate only their own
  typed test fixtures.
- Frayed-edge tests remove known morphological, causal, temporal, and structural edges
  and require typed hypotheses rather than asserted facts.
- A constrained-vacancy fixture predicts the missing role's physical, relational,
  temporal, and counterfactual signature from surrounding structure. An unrelated
  zero-row query cannot emit the same discovery object.
- Candidate entities, physicalities, relation families, motifs, laws, operators,
  firmware operations, and cognition programs retain their extension kind and current
  calculus version throughout generation, experiment, and activation.
- A predicted occupant that fits every surrounding constraint remains derived and
  leaves the vacancy epistemically unfilled until eligible observation or testimony
  arrives.
- Missing-relation candidates are generated and fitted separately from their pinned
  evaluation evidence. Training-energy improvement or evaluation leakage fails the
  candidate experiment.
- AImap modes pass eigenpair residual, orthogonality, null-space, principal-angle,
  gauge, independent-solver, incremental-update, and coherent-epoch checks. Their
  deletion cannot remove canonical semantics.
- Hypotheses preserve generator, evidence on both sides, world, time, predicted
  observation, test, and resolution state.
- Counterfactual state cannot mutate canonical state.
- Observe, Orient, Decide, Act, and consequence observation produce separate typed
  receipts. The effect outcome re-enters through content, physicality, occurrence,
  testimony, and receipt layers, and the complete cycle replays exactly.
- Fast cognition, evidence-epoch learning, and calculus-changing discovery have
  distinct state transitions. A query cannot silently change standing, adjudication
  cannot silently change a relation law, and a candidate cannot activate itself.
- Self-generated rules, predictions, and descendants retain their ancestry and add no
  independent support to their own activation claim.
- Identical world state, goal, firmware version, tie rules, and seed produce identical
  decision traces; different firmware artifacts produce their declared computational
  divergence before language realization.
- Godel rule induction must rediscover withheld rules, survive unseen examples, weaken
  under supplied exceptions, and reject accidental correlations that lack predictive
  utility.
- Working-state load, update, strategy shift, inhibition, reference resolution,
  pragmatics, and goal termination are tested independently and as one conversation.
- Semantic act selection precedes modality realization. Japanese, Spanish, image,
  audio, code, and model realizers consume the same typed semantic plan without an
  English token sequence as a universal intermediate.

## Installation and product lifecycle

- Clean install, repeated install, upgrade, repair, and uninstall execute through public
  package commands and produce independently verified state.
- Repeating the same command converges on the same product state.
- Packages contain exact manifests, checksums, licenses, provenance, and SBOMs.
- Services start with explicit configuration, health, readiness, and diagnostics.
- Linux and Windows packages pass the same product behavior requirements.
- Every process reports the exact loaded native objects and perfcache epoch; unexpected
  system GEOS, PROJ, or another undeclared dependency fails readiness.

## Release decision

Laplace is releasable only when the required complete-product suite passes against the
packaged installation. Individual component success cannot override a failed product
acceptance.
