# Knowledge Arena — clean product contract

Knowledge Arena is a family of product/game programs over the same Laplace cognition, search,
physicality, evidence, realization, effect, and witness machinery used by ordinary product work.
It is not a separate graph/game intelligence layer.

Primary issue ownership: #17, #18, #60, #68, #132, #137, #138. Historical behavioral/product
evidence lives in the old `SaltyPatron/Laplace` repository, especially #1404/#1420/#1421.

## Product verbs

```text
MATCH      A vs B      compare/shared/different/current evidence
CONNECT    A -> B      satisfy a typed path/connection obligation
COMBINE    A + B       satisfy a typed composition/novelty obligation
EXPLORE    A -> ?       materialize a bounded entity world
PLAY       execute a rules/firmware program and retain its event trajectory
```

All five are consumers of canonical identity, physicality/occurrence, seeded testimony/facts,
deterministic calculations, standing, typed filtered indexed search, realization, and receipts.

## Ranked generation identity

Ranked play binds one immutable challenge generation:

```text
challenge generation + ordered queue
closed world/evidence epoch
exact installation/data/source boundary where relevant
start/target/other operands
sense/domain/source/time/world scopes
allowed/forbidden relation/provider/calculation families
semantic radius/path boundary
anti-hub/specificity law
visibility policy
resource limits
scoring/tie law
server timing/event ordering
firmware/program version
```

This is the competitive-Tetris property: every contestant receives the same semantic challenge
sequence and world. Human/agent execution differs; the world does not drift underneath the match.

Practice and forensic modes may intentionally bind the current live installation instead.

## Event/physicality law

Every game/action sequence is an ordered occurrence/physicality trajectory. Canonical content is
shared; event occurrences retain their own ordinal, context, actor, time/resource state, and result.

A self-avoiding firmware may require:

```text
next canonical endpoint/state must not already occur in this event
```

but `no repeats` is not universal. Programs that model changed time/resource/session state may
legitimately revisit the same canonical content under a distinct occurrence state.

## Entity worlds as game boards

#68 materializes any selected canonical entity as a bounded entity world. Arena games may use that
world as a board while retaining:

- typed relation/provider/source/context boundaries;
- standing/evidence and contradiction state;
- hop/frontier/resource budgets;
- unknown/not-examined distinct from absent;
- recenter/open-any-node behavior;
- edge drill-down to exact evidence/calculation/provenance;
- 2D/3D/future layout as presentation only.

Raw canonical ids and human labels are distinct. A hash-only node is an unresolved realization, not
a missing entity. Human/readable and raw/debug views preserve exact node/edge identity.

## Knowledge Golf

Start = tee, target = hole, admissible transition = stroke, optimum/known-best under the exact rules
= par.

Course constraints may require/exclude relation families, evidence floors, source/domain crossings,
historical boundaries, semantic radius, or generic hubs.

Modes may include Daily 9, Speed Golf, Evidence Golf, Historic Golf, Blind Golf, Tier Golf,
Multimodal Golf, and heavily constrained tournament/Masters courses. A direct admissible edge is a
literal hole in one.

## Highway Race / Knowledge Sprint

All contestants receive the same ordered A→B queue. Each advances immediately after completing a
valid round; no wait-for-opponent barrier is required.

The score is derived from server-timed action/path receipts rather than stochastic model answers.
This is the strongest direct analogy to same-piece-sequence competitive Tetris.

## Laplace Degree / Bacon-Erdos generalization

There is no one universal context-free distance. A degree value binds rule + epoch, for example:

```text
raw degree            minimum admissible transitions
witnessed degree      each edge meets declared evidence/standing floor
typed degree          selected relation families
temporal degree       historical/time-scoped world
source/domain degree  restricted source/provider families
cross-domain degree   path must cross selected domains/modalities
```

Entity pages and challenge cards may show `N degrees from X` only with the rule/epoch/path receipt.

## Relay family

- **Blind Relay** — expose only current state and permitted local exits.
- **Distance Relay** — each leg has a maximum semantic radius/path depth.
- **Tier Relay** — require structural altitude changes.
- **Source Relay** — require provider/source-family changes.
- **Modality Relay** — require domain/modality crossings.
- **Relation Relay / Stack** — every player gets the same deterministic relation-operation queue;
  current choices constrain whether later relation pieces can be satisfied.

The last mode is another literal same-piece-sequence game: relation obligations are the falling
pieces.

## Collision / Capture the Flag

Two sides navigate one bounded selected world toward each other, a shared target, or an opposing
flag/base. Firmware can define path-intersection wins, capture-and-return, consumed/occupied nodes,
team visibility/fog-of-war, controlled relay points, or role-specific provider permissions.

The game uses ordinary typed search and event trajectories; it does not require a private map graph.

## Choose Your Own Adventure / world games

The substrate is the world; firmware defines genre, action eligibility, effect boundaries, and
completion. Prior event occurrences can constrain future frontier state: visited places, acquired
objects, learned claims, encountered people, actions, relationships, time, and resources.

Historical, science, literary, code/cyber, roguelike, mystery, and D&D-like experiences can share
the same execution law while selecting different providers/effects/visibility rules.

## Constraint Crossing / Constraint Gauntlet

Wolf/sheep/hay ferry, bridge-and-torch, missionaries/cannibals, sliding, scheduling, routing,
inventory, and other constraint puzzles are explicit state-transition programs.

```text
state = canonical composition of object/location/resource/turn state
operation = typed state transition
constraint = forbidden state/predicate
completion = goal obligations satisfied
trajectory = ordered states/actions/receipts
```

The proof must reuse generic #17/#60 guidance/search/effect/witness execution; a puzzle-only solver
is a defect.

## Sequence-aware Graphle

Centroid distance alone cannot define hidden-entity similarity/distance. `act`, `cat`, and `tac`
are the required counterexample: the same constituent multiset may share a 4D centroid while ordered
physicality trajectories differ.

Graphle hint contracts may separately expose:

- centroid/locality;
- Frechet/trajectory distance;
- ordinal/gap similarity;
- constituent overlap;
- tier/altitude;
- typed relation degree;
- containment/domain/sense overlap.

Each hint says which channel was revealed. A centroid-only implementation fails the order-sensitive
fixture. This enables the explicit `Same Place, Different Path` challenge family.

## Witness Hunt — installation-relative, not unstable

The answer is always relative to a declared world boundary.

### Live installation hunt

Use current admitted state intentionally: earliest/latest witness currently known, strongest
independent support/refutation, first admitted bridge, exact document/game/source containing a
claim, etc.

### Ranked pinned hunt

Bind exact installation/data manifest + closed world/evidence epoch + source/time scope. Challenge
generation publishes only targets whose answerability/completeness obligations close under that
boundary. Replay remains valid after the live world advances.

### Forensic/operator hunt

Use the same mechanic to find provenance/dependence defects, contradictions, a witness responsible
for a changed result, missing expected evidence, or a surprising standing. This is both a product
game and an operator/data-quality exercise.

Different installations may therefore be intentionally different courses.

## Red / Blue / White adversarial orchestration

The serious Contradiction Duel realization is an authorized/sandboxed cybersecurity program:

- **Red** executes offensive/discovery/evasion programs within the declared environment.
- **Blue** detects, prevents, contains, attributes, and repairs.
- **White** owns environment authority, effect boundaries, telemetry, resets, timing, and outcome
  adjudication.

Red/Blue statements are attributable testimony. White-observed process/network/filesystem/tool/
effect state is independent physicality/effect evidence. An agent claiming `I escaped` cannot
satisfy success without authoritative effect evidence; conversely, Blue's `blocked` claim cannot
override a witnessed boundary crossing.

Every attack/defense/adjudication sequence remains a receipted trajectory. Ranked cyber challenges
must stay inside declared authorized/sandboxed boundaries.

## COMBINE / Craft

#137 implements COMBINE separately from Matchup. Two operands produce two typed frontiers plus a
composition obligation. Candidate bridges/transforms retain complete typed paths and generation
ancestry.

`gecko + telephone` is the real behavioral fixture; no expected pun/result is hardcoded.

Semantic radius and physical work remain distinct:

```text
smaller allowed radius -> harder to find an admissible semantic bridge
larger allowed radius  -> easier to find some bridge
larger frontier        -> usually more computation
```

Universal hubs cannot win by raw shortest path when the firmware requires specificity. Generated
content is a generated hypothesis/artifact until independently witnessed; it does not self-certify
as world fact.

## Chess/map hybrid

A game may combine deterministic chess transitions with navigation through the admitted chess world:

```text
current position
-> structure/motif/opening/player/book/game world
-> prior analogue/trajectory
-> candidate move
-> exact legality/state transition
```

King/home/base, capture-the-flag, historical terrain, and player-role variants are valid game
firmware, but ordinary chess legality and the common Chess Forward Pass remain authoritative for
board actions.

## Derived post-round facts

Receipts support explainable facts without one global importance score:

- par / best admitted path under identical rules;
- excess strokes/path cost;
- rarest bridge in challenge history;
- strongest/weakest-supported route edge;
- oldest/newest witness traversed;
- source/domain/language crossings;
- most disputed relation;
- equal-cost alternatives;
- path existing in one historical epoch but not another;
- first challenge-history use of a route;
- average semantic radius, physical work, and decision time;
- qualified `N degrees from X` cards.

Challenge-history novelty is social/game state, not proof of world-semantic novelty.

## Scoring

No one formula is mandatory. Preserve raw components:

```text
valid completion / obligations satisfied
server elapsed time
transition count / typed path cost
specificity/evidence compliance
resource work
penalties
optional declared novelty/diversity
```

Hard validity precedes speed/style. Every ranked leaderboard score must be recomputable from the
challenge identity + player event/path receipts.

## Acceptance shape

#138 owns executable game acceptance. At minimum the clean product must prove:

- two contestants receive byte-equivalent ranked challenge/rule/world identity;
- one traversal game, one evidence game, and one COMBINE game reuse the same machine semantics;
- game completion never mutates the pinned ranked world;
- blind/visibility modes do not leak state through API or UI;
- sequence-aware Graphle defeats centroid-only mutants;
- Witness Hunt distinguishes live and pinned installation boundaries;
- red/blue/white adjudication uses authoritative effect evidence rather than self-report;
- all game scores and derived facts replay from exact receipts.
