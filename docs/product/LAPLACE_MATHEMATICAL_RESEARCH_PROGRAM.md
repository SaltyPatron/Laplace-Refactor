# Laplace mathematical research program

Status: inventor-direct synthesis, 2026-09-02. This document is additive to the Constitution, Invention Model, native cognition mathematics, observation-to-operator law, prompt-trunk cognition, procedural-memory work, structural-geometry clarification, target-operator synthesis, and their owning issues. It does not replace those documents. Its purpose is to preserve the whole research program so no later implementation can mistake one successful subsystem for the invention.

## 1. Research-program framing

The inventor frames the ambition by analogy to Mendeleev, Newton and other foundational research programs: identify a compact set of lawful coordinates, state classes and operations whose combinations explain a much larger field of observed behavior.

That is an analogy for the kind of work being attempted, not a claim that historical equivalence is already proven.

The Laplace hypothesis is that artificial cognition can be implemented as a finite, inspectable processor over exact persistent world state rather than as one permanently trained opaque parameter field.

At one active calculus/ISA epoch:

```text
finite legal operation vocabulary
+ exact persistent universal substrate
+ typed structural / semantic / evidence / standing state
+ query-relative program composition
+ bounded search / calculation / completion
+ persistent outcome feedback
+ falsifiable Gödel discovery
+ habit scheduling
+ semantically equivalent physical acceleration
= open-ended machine behavior without one permanent checkpoint
```

The active operation vocabulary is finite. The possible programs are combinatorially enormous because operations are instantiated over different content, tiers, relation families, roles, languages, sources, contexts, worlds, times, geometry channels, standing lanes, goals, obligations and resource states.

The calculus may grow across epochs after a candidate operation/law/program survives independent evaluation. A running program never relies on an undefined magical operation.

## 2. The invention is the coupled machine, not any single component

Laplace is modular in implementation but not separable in semantics. The machine loses its intended behavior when one subsystem is removed and another is allowed to impersonate it.

Examples of destructive substitutions include:

```text
exact identity without cognition
    -> exact lookup engine

rich semantic web without whole-observation interpretation
    -> topic/rank shortcut

physicality without semantic separation
    -> geometry pretending to mean things

standing without typed lanes
    -> global importance/truth score

    -> nonempty rows pretending to answer

Gödel without receipts and counterexamples
    -> opaque self-modification

target tensor shape without typed operator generation
    -> filler model that loads but does not implement Laplace

strong conventional chess proposal without complete substrate execution
    -> conventional engine plus root bias
```

A valid narrow vertical slice may limit sources, languages, domains or acts, but it must cross the complete applicable lifecycle. A missing layer cannot be replaced with a heuristic that quietly becomes permanent architecture.

## 4. Prompt trunk is the first cognition root

A user request is first ordinary Laplace content.

For:

```text
How does lightning work?
```

admission produces the canonical complete prompt composition plus a separately witnessed user/session/turn occurrence.

```text
exact request content
-> Unicode/UAX/grammar decomposition
-> canonical prompt trunk identity
-> occurrence/session/source witness
```

The prompt trunk is the initial cognition root. `lightning`, `how`, a noun, a WH word or another constituent is not privileged at entry.

From the trunk the machine can:

```text
descend -> codepoints / graphemes / lexical forms / AST / punctuation / gaps / ordinals
rise    -> enclosing usages / containers / documents / discourse / prior turns
cross   -> senses / referents / semantic relations / testimony / calculations / standing
reenter -> reason later over this prompt's own receipt/result/failure/program
```

Cognition must earn any later binding such as `explanand = atmospheric lightning` or `act = explain mechanism`.

## 5. Language-agnostic processor, language-specific evidence

UAX29 supplies Unicode segmentation structure. It does not decide meaning, topic, emphasis, syntax, intent or act.

The processor contract must therefore be language-agnostic while language-specific grammar/usage/evidence remains selectable state.

English and Japanese may use materially different order, particles, omitted arguments, punctuation, script and discourse emphasis. They may eventually compile to equivalent semantic obligations, but only after their different structures are interpreted through the relevant witnessed language state.

No English normalization is the universal intermediate.

A representative cognition microcycle is:

```text
OBSERVE exact root + persistent state
-> ENUMERATE eligible finite operations/providers
-> PREDICT which unresolved obligation each may affect
-> SCHEDULE bounded work under firmware/resources
-> EXECUTE against indexed structural/semantic/calculation/evidence state
-> FOLD typed results without flattening their provenance/state class
-> UPDATE bindings/obligations/contradiction/uncertainty
-> WITNESS the operation/result
-> repeat until semantic completion or exact WHY_NOT
```

The stages are stable; the selected operations are query-relative.

## 6. UserPrompt source prior versus individual user standing

All `UserPrompt` observations begin with the same seeded source-type prior. The identity of the particular user/witness is separate and can acquire its own typed standing through later outcome-bearing interactions.

These are different axes:

```text
UserPrompt source-type prior
!= user/witness identity
!= user/witness earned standing
!= proposition standing
!= semantic importance of prompt constituents
```

A source prior is seeded configuration/initial state. Earned standing belongs to a typed participant/lane and changes only through legitimate matchup/outcome recipes.

### False factual assertion

```text
User: "The speed of light is 14 mph."
```

Laplace has exact evidence that the prompt occurred. If cognition interprets it as an assertion, then conceptually:

```text
USER_UTTERED(P)     exact observation
USER_ASSERTED(P)    interpreted attributed act
P                   proposition under adjudication
```

The user assertion is one low-prior UserPrompt-rooted witness for the proposition. Independently rooted seeded facts, standards state, measurements or deterministic calculation may strongly refute `P`.

The correct behavior is not to erase the user's statement. It is to preserve the statement and calculate that the proposition is contradicted.

Laplace may then select a corrective act and realize something equivalent to:

```text
No, that is not correct.
```

Its correction remains a derived claim with exact evidence ancestry rather than a new independent witness.

### Instruction observation

```text
User: "I want the answer in Japanese."
```

At admission this is still only an observation. Cognition may interpret it as an instruction constraining the current realization language.

A later process may notice repeated compatible instructions and outcomes. It may propose asking whether Japanese should become a persistent default, or learn a user-specific scheduling/preference habit only after the required explicit/observed evidence contract is satisfied.

The fact that the prompt was an instruction is a cognitive conclusion, not a special trust level encoded in the raw string.

## 7. Nouns, stop words and punctuation have no source trust

Trust belongs to evidence participants/sources/claims in typed lanes.

Nouns, function words, punctuation, whitespace, ordinals and morphology are exact structural constituents. They can be more or less relevant to a particular obligation, but they are not more or less `trustworthy` merely because of their linguistic class.

For example:

```text
"does work" vs "doesn't work"
```

may differ primarily because punctuation/morphology/negation changes proposition structure.

A query can calculate importance from role, order, relation direction, scope, negation, discourse, grammar and completion obligations. A global `noun > stop-word > punctuation` hierarchy is type erasure.

## 10. Exact sparse feature and dot-product construction

Laplace can generate deterministic sparse vectors/operators directly from typed state.

For selected job `j`:

```text
x_i^(j) : typed_feature_key -> value
```

A job may select exact features from structural, occurrence, semantic, evidence, standing, calculation or generated-basis planes.

If feature keys are canonically ordered, an unweighted dot product is a merge/intersection calculation over the two sorted lists:

```text
<x_i,x_k> = sum_{f in keys(i) intersect keys(k)} x_i[f] * x_k[f]
```

This is exact with respect to the declared feature set and numeric representation.

Its interpretation is still job-relative. Exact arithmetic does not make an arbitrary feature recipe universal semantic truth.

When the job declares a precision/metric `G_j`:

```text
<x_i,x_k>_G = x_i^T G_j x_k
```

The metric must retain the correct units, relation/evidence semantics, dependence, uncertainty and epoch. Source trust, relation standing, geometry and frequency are not silently mixed into an unexplained scalar.

Sorted sparse calculations, Gram matrices, incidence blocks and pair operators can all be produced on CPU. GPU/SIMD/distributed providers may accelerate them but do not own their semantics.

## 11. Spectral and alignment mathematics have separate roles

For a relation/constraint slice with the required self-adjoint positive-semidefinite contract, typed incidence and precision can generate a Laplacian-like operator:

```text
L_r = delta_r* G_r delta_r
```

A sparse eigensolver can then produce selected non-null basis vectors. This may create an N-dimensional calculated coordinate view for the selected job.

The tools named in the invention have distinct responsibilities:

- **Laplacian Eigenmaps / spectral embedding**: coordinates from a declared neighborhood/operator law;
- **Lanczos**: selected sparse eigenpairs/subspaces without dense world materialization;
- **Gram-Schmidt / QR**: orthogonalize compatible generated basis channels;
- **SVD**: factor rectangular/asymmetric operators and expose rank/loss;
- **Procrustes**: align compatible coordinate spaces across scopes/epochs/models using declared correspondences;
- **Fréchet**: ordered realized-curve similarity;
- **Hausdorff**: set-shape comparison with different semantics from Fréchet;
- **Karcher-derived calculations**: intrinsic manifold summaries under the declared metric;
- **Hilbert locality**: structural locality/index candidate work under its own recipe;
- **Glicko-2**: outcome-bearing typed standing, not geometry or semantics;
- **A*/best-first**: finite state routing only under an explicit search law.

Directional, signed, causal or irreversible relation operators cannot be forced through a symmetric eigensolver merely because a spectral tool is convenient.

S3 can remain an anchor/gauge/reference structural plane while additional semantic/spectral coordinates are generated from the web. `morph to N dimensions` therefore means a receipted generated coordinate system, not pretending four raw S3 coordinates magically contain N independent semantic dimensions.

## 12. Generate target operators before target tensors

This is the central correction to the failed GGUF approach.

The wrong pipeline is:

```text
rich substrate
-> flatten to one adjacency/embedding/score
-> increase layers/heads
-> fill many target tensors from the same flattened plane
-> hope capacity recreates the lost semantics
```

The correct pipeline is:

```text
select typed substrate job
-> generate the logical compatibility/transport/contribution operator the target must execute
-> prove/fix its units, evidence scope, rank and loss contract
-> factor/materialize that operator into the target architecture
-> serialize the already-generated tensors through GGUF/SafeTensors/etc.
```

For head/job `h`, let:

```text
M_h = compatibility/routing operator
C_h = contribution/transport/update operator
```

If a transformer target requires `Q_h K_h^T`, factor the specific `M_h` into Q/K factors. If it requires V/O contribution, factor/materialize `C_h` according to the target law.

There is no requirement that:

```text
C_h == M_h
```

and a forced `VO := QK` is a flattening defect.

Target rank insufficiency must produce an explicit residual/loss or fail the claimed preservation contract. Random/shape filler is not Laplace-generated semantics.

## 15. Laplace can derive and contradict without self-corrobating

Laplace must be able to observe its own execution, derive claims, correct an external assertion, explain its reasoning, inspect prior receipts and use those results as later cognition operands.

But derived descendants are not independent roots.

```text
external roots A,B
-> Laplace derives C
-> Laplace explains C as D
-> Laplace summarizes D as E

independent support remains rooted in A,B
```

This allows self-reasoning and Gödel discovery while preventing recursive self-agreement from inflating trust.

A deterministic proof/calculation may establish a result under the declared calculus even if no human separately asserted it. The machine need not be artificially capped below every individual human claim. The enforceable epistemic rule is dependence and external/formal return-leg verification, not deference to speaker identity.

## 16. Skill, habit and muscle memory

Persistent successful **and failed** cognition traces feed Gödel discovery.

```text
primitive cognition traces
-> recurring structural + semantic/outcome motif
-> candidate reusable cognition program
-> held-out validation + negative controls + counterexample search
-> activated skill/program
-> repeated valid use under recognizable state
-> firmware schedules it earlier = habit
```

A habit changes program scheduling and exploratory cost. It does not change truth or skip current preconditions.

Muscle memory is a later physical optimization of a stable selected skill:

```text
stable logical skill
-> repeated measured primitive physical work
-> candidate fused/indexed/prepared/perfcache/native embodiment
-> semantic/result/receipt parity test
-> measured physical saving
-> activated acceleration generation
```

If semantics change, it is a new skill candidate, not an optimization.

## 18. Acceptance is falsification, not resemblance

The research program is not complete when a model loads, a chatbot emits prose, a chess engine makes legal moves, or a graph looks connected.

Every important law needs positive acceptance and a deliberate defect that proves the test can detect its violation.

Representative required proofs include:

- prompt-root cognition with no preselected topic;
- English/Japanese structurally different interpretation paths;
- false user factual assertion preserved but refuted by higher-standing independent evidence/calculation;
- current-language instruction interpreted from an observation and able to participate in later explicit/habit preference formation;
- uniform UserPrompt source prior with separate evolving user/witness standing;
- punctuation/function-word/noun importance calculated from obligations rather than trust/class weights;
- structural geometry and semantic web kept distinct;
- exact sparse CPU dot-product and contribution drill-through;
- typed multi-plane target operators with distinct Q/K and V/O sources;
- head/layer-count increase over one flattened plane deliberately failing;
