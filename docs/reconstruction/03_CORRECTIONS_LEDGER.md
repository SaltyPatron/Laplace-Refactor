## Rule for new corrections

When a later primary source or inventor correction invalidates a reconstruction statement:

1. append a row here;
2. identify the wrong statement rather than silently deleting history;
3. state the corrected rule and authority class;
4. list every dossier section affected;
5. update those sections;
6. leave unresolved portions unresolved until researched.
