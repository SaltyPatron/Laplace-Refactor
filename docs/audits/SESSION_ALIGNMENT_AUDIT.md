# Session alignment audit

## Finding

Laplace is not waiting for another idea, another reduced demonstration, or a narrower
product definition. The inventor has supplied the architecture and the required
behavior. The work is to implement the complete invention cohesively, prove it through
the implementation, package it as a product, and preserve the technical record of what
was previously lost or misrepresented.

The current implementation is not the product definition and is not a completeness
boundary. It contains useful historical evidence, upstream dependency assets, measured
counterexamples, and partial experiments. It also contains duplicated authorities,
unproved behavior, missing work, stranded work, orchestration code performing engine
work, SQL performing engine work, and tests that can pass without proving the claimed
mechanism. No Laplace implementation is carried into the new repository.

This audit is the alignment baseline for the new repository. A later correction from
the inventor changes this baseline explicitly; ordinary sequencing never narrows it.

## Product completion condition

The intended outcome is one product named **Laplace** at the canonical repository and
installation locations. It must be all of the following at once:

- a complete reinvention of transformer execution through SQL;
- a universal persistent substrate for every modality and future modalities;
- a native C/C++ engine integrated with PostgreSQL through extension and server APIs;
- SQL and C# orchestration over one typed, versioned, vector-first ISA;
- an executable relational world model with explicit evidence, trust, time, context,
  goals, inference, hypotheses, counterfactuals, valuation, and receipts;
- a persistent conversational intelligence with no token-window memory boundary and
  no softmax answer invention;
- a model witness, comparison, synthesis, and export system whose target artifacts can
  converse and execute the required behavior;
- a high-throughput bulk ingestion and execution system;
- an installable, supportable Linux and Windows product with reproducible custom
  PostgreSQL, PostGIS, GDAL, GEOS, PROJ, and complete dependency builds.

None of these is a later side project. Their implementation order is a dependency
order inside one completion condition.

The current implementation is not called an obsolete product, and the new product is
not named as a refactor, rebuild, successor number, or derivative. The archive records
an implementation history. The canonical product remains Laplace.

## Architectural authority

### Engine boundary

The engine is C/C++ plus PostgreSQL server integration. It owns identity,
canonicalization, decomposition, composition, physicality, relation operations,
testimony, trust mathematics, adjudication, traversal, selection, inference,
conversation semantics, Godel rule operations, firmware execution, model operations,
materialization structure, concurrency kernels, and receipts.

SQL and C# are both orchestrators.

- SQL owns schemas, tables, indexes, constraints, transactions, set routing, typed
  native bindings, program composition, and result projection.
- C# owns source and service lifecycle, bounded work scheduling, transport protocols,
  authentication, product authorization, billing, user interfaces, telemetry, and
  package commands.
- Neither SQL nor C# contains a private semantic engine.
- PostgreSQL SPI and native extension entry points are normal engine surfaces, not a
  reason to implement row-by-row logic in an orchestrator.

### Single execution authority

Every semantic operation has one canonical native implementation and one declared ISA
meaning. Scalar calls use the same implementation as vector calls. SQL declarations,
C# bindings, documentation, ABI tests, and package manifests are generated from one
contract where generation can eliminate duplication.

Native abstractions use typed generic vector, set, trajectory, relation, evidence,
program, and receipt interfaces where the semantics are genuinely shared. Generic
code is not an excuse to erase types, and interfaces are not an excuse to create many
implementations of one operation.

No path is accepted merely because it returns the expected shape. The executing
binary, instruction version, data epoch, inputs, outputs, and receipt must be exact.

## Complete requirement coverage

### Universal substrate and identity

- Same canonical content means the same content identity regardless of source,
  language, modality, model, ingestion route, tier, location, or time.
- A content-changing transformation creates a new content identity and a witnessed
  relation to the original.
- An entity contains identity only. Physical realization, declared type, inferred
  classification, interpretation, and occurrence do not become entity fields.
- Exact Unicode compositions remain distinct even when a pinned standard produces a
  semantic-equivalence attestation between them.
- Content identity and referential identity are separate. Names, pronouns, aliases,
  roles, and descriptions can refer to the same external entity only within explicit
  evidence and context.
- Recursive ordered and unordered composition has no modality-specific ladder and no
  fixed maximum depth.
- Structural tier is a floor, not a semantic type and not part of content identity.
- Text, images, audio, video, code, games, model state, and future media use the same
  core identity, composition, relation, evidence, execution, and receipt laws.
- Edge codecs handle containers and encodings; they do not create separate substrate
  implementations.
- Every addressable piece of substrate state can become program input directly. No
  prompt-copy layer and no token-count horizon defines what can be remembered.
- Cross-modal queries accept one modality and return another through the same core
  execution law. Engine-stage throughput and latency parity are measured across
  modalities, while codec time and source byte volume remain separately visible.

### Physicality and topology

- Physicality is an immutable calculated realization expressing structural form,
  dimensions, placement, locality, shape, order, multiplicity, and serialization.
- A source declaration is an attestation about an entity or physicality, not a way to
  instantiate physical structure. A classifier result is a derived attestation with
  complete calculation lineage.
- Observed use creates an occurrence and context; it does not mutate physicality.
- One entity can have several versioned physicalities under different legitimate
  realization recipes or geometry epochs.
- S3 coordinates, centroids, angular distance, Hilbert locality, constituent
  trajectories, ordinals, packed metadata, realized curves, and Frechet distance are
  distinct operations.
- Packed constituent identity is never treated as a coordinate curve.
- Hilbert values support indexed locality, gap detection, and candidate discovery.
- Geometry proposes and organizes candidates. Relational evidence decides standing.
- Equal centroid, radius, or Hilbert locality never establishes equal identity,
  constituents, trajectory, or meaning.
- Traversal crosses the substrate graph and topology; isolated dictionary lookup does
  not satisfy query or conversation behavior.

### Evidence, trust, and truth state

- Assertions retain witness, source, source type, relation type, context, observation
  outcome, score, uncertainty, count, temporal facts, and provenance.
- Source trust, source-type trust, relation trust, model trust, context trust, and
  individual experience remain independently queryable.
- Confirmation, refutation, uncertainty, absence, unsupported, and unknown remain
  distinct through persistence and query.
- Negative material can reduce the standing of a contradicted proposition.
- Adjudication never deletes or flattens the testimony that produced it.
- Repetition from one source is not independent consensus.
- Witnessed, copied, derived, independently corroborated, and currently believed are
  distinct epistemic kinds.
- Every derivation retains an acyclic provenance DAG and complete root-observation set;
  descendants and cycles cannot multiply independent support.
- Mirrors, quotations, shared primary sources, duplicated datasets, model ancestry,
  fine-tunes, distillation, and common corpora form an evidence-dependence graph used
  by adjudication.
- Consensus is an immutable, reproducible, time-addressable epoch over an exact
  testimony boundary. A new epoch never rewrites prior testimony or standing.
- Definitions are testimony. Understanding requires stable, diverse, consistent,
  independently supported relations and successful use or prediction.
- Recorded observations and calculated conclusions remain distinguishable.
- Shared world claims and individual observations coexist without converting a
  personal preference into a universal proposition.

### Relation algebra and inference

- Every relation declares or learns its direction, inverse, symmetry, reflexivity,
  transitivity, composition laws, confidence behavior, temporal behavior, contextual
  scope, and counterexample state.
- The engine composes only relations whose typed laws authorize the composition.
- `WIP is-a WOP` permits WIP-to-WOP reasoning and forbids the converse conclusion.
- Causal, predictive, temporal, categorical, sensory, linguistic, autobiographical,
  procedural, social, and probabilistic relations remain typed.
- Association, prediction, precedence, enablement, necessity, sufficiency, causation,
  and explanation are not interchangeable.
- A relation property learned from repeated observations remains a tested hypothesis
  until counterexample search and evidence establish its standing.

### Executive cognition

- Thought is goal-conditioned dynamic trajectory construction through the persistent
  relational world model.
- Goals are first-class values containing objective, constraints, success condition,
  evidence threshold, resources, cost boundary, and termination condition.
- The executive schedules candidate trajectories using relevance, evidence,
  information gain, novelty, expected value, computation cost, and firmware policy.
- Working state holds salient entities, propositions, unresolved references,
  hypotheses, current trajectories, discourse commitments, and the active goal.
- Updating, strategy shifting, and inhibition are executable operations, not prose
  instructions.
- A stored trajectory is memory; a newly derived trajectory is inference; a new bridge

- Perception, sensor state, action, embodiment, motor effects, self-model, episodic
  memory, drives, emotional or salience value, social models, and active experiments
  use the same typed world-state and program machinery rather than disconnected
  cognitive products.

### Hypotheses, contexts, and time

- Observed, attested, inferred, hypothesized, predicted, contradicted, refuted,
  unsupported, and unknown are first-class and cannot silently collapse together.
- A hypothesis records its generator, evidence for, evidence against, context,

- Counterfactual execution occurs in an isolated world state and cannot contaminate

- Propositions carry world and scope: physical reality, a mathematical proof, a

### Pattern induction, frayed edges, and Godel operations

- Repeated relational motifs create defeasible expectations about missing nodes,
  edges, roles, or procedures.

  converting the hypothesis into an observation.
- Morphological relations are learned from structure and context across languages;
  suffixes are not assigned a universal meaning.
- Surface transformation and semantic relation remain distinct, including grammatical
  gender versus a referent property.
- Higher-order structure can recognize analogous relation motifs across unrelated
  strings, scripts, and languages.
- Godel operations compare successful and failed trajectories, propose higher-order
  rules, search for counterexamples, measure compression and predictive value, and
  synthesize exact candidate cognition programs.
- Candidate abstractions earn standing through compression, unseen prediction,
  counterexample survival, cross-context generalization, reduced reasoning cost, and
  improved outcomes. Accidental correlations do not become engine law.
- Proposed cognition programs are replayed and measured before exact artifact
  activation. Discovery never silently changes the executing mind.

### Generated native cognition mathematics

- Laplace calculates and generates the representation and operator required by a
  cognition program. It does not flatten all relations into one permanent graph,
  scalar adjacency, embedding, or model.
- The universal contract is a typed calculus over exact entity, physicality,
  occurrence, testimony, epoch, context, relation-law, and goal state.
- A relation occurrence can generate a typed compatibility term
  `(delta x)_r = x_j - T_r x_i`; `T_r`, its fields, direction, arity, units, time, and
  context come from the relation algebra.
- The evidence metric `G_r` is calculated over the typed defect space from eligible
  testimony, root independence, dependence, contradiction, trust dimensions, time,
  context, and the immutable epoch receipt.
- `delta* G delta` is a candidate induced operator family. It is not permission to
  average relation types or persist every generated edge.
- The field/operator calculation, typed defect and innovation calculation,
  deterministic counterfactual act selection, and modality realization remain
  separate stages.
- Solver residual is not frayed structure. Existing-relation compatibility, unsatisfied
  boundaries, missing motif roles, observation innovation, independently supported
  contradiction, and counterfactual effects are distinct typed defects.
- Missing-relation value is measured against a pinned evaluation boundary that was not
  available during candidate generation or fitting. Improved training energy cannot
  certify a candidate.
- A natural-language or multimodal request compiles into a typed logical cognition
  program before the native planner generates and costs a physical ISA plan.
- S3 physicality and AImap operator coordinates are distinct coordinate systems over
  the same entity. AImaps are generated, receipt-bound modular perfcaches, not
  physicality or canonical meaning.
- Spectral modes are compared by eigenpair residuals, orthogonality, eigenspace
  projectors, and induced behavior. Sign, degenerate-subspace rotation, Procrustes
  alignment, and model gauge cannot become semantic differences.
